Reading the passive-improvement sequence

The 2026-10-21 log in results/IMPROVE.md records cheaper gold, bonus-bucket tax treatment, spending settings, combined loans, stacked-fund proxies, glidepaths, harvest rules, changing allocations, additional trend exposure, crash leverage, phase-in and real-asset ideas. Many were rejected or retained only as optional trade-offs. Use the JSON metrics and reference specification from each run; do not reconstruct a conclusion solely from a summary paragraph.

results/FINDINGS.md gives the broader running record. git log --oneline -- printer strategy lab results shows changes to the methods and conclusions. This preserves public research decisions without publishing raw household conversations.

Known evidence gaps

  • Seeds used repeatedly during development are no longer untouched validation seeds.
  • New bootstrap paths are not new market regimes. Model risk, multiple testing and shared proxy errors remain.
  • The legacy acceptance predicate permits small absolute risk regressions; read METHOD.md before repeating the phrase “no worse.”
  • The latest selected settings still need prospective tracking and independent replication.
  • Life expectancy estimates, healthcare assumptions, benefits and taxes need broader review and jurisdiction-specific modules.
  • The data pipeline still depends on third-party historical caches and an undocumented external API in places.

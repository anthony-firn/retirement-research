Retirement tools
Research library

Retirement research, open to improvement

Understand the evidence, compare the trade-offs, and help improve retirement decisions for everyone.

Start with your needs

How much must your savings cover each month? When will other income begin? What changes if markets disappoint?

The tools estimate possible outcomes. Simulated income is not guaranteed, and many early fund histories are reconstructed.

How to read a result

Compare the early paycheck, bad outcomes, pay cuts, depletion, costs, taxes and complexity alongside the average.

Changing the order of historical returns tests different paths through known data. It does not tell us every future that can happen.

This library is bundled with the mobile app and cached for offline browser reading after installation. Live calculations and tracker changes need your server.
